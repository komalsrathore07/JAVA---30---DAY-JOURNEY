# Day 09 - Array Analyzer

A Java console-based Array Analyzer project created as part of my 30-Day Java Learning Journey.

## 🎯 What This Project Does

This project uses an array and loops to analyze a collection of numbers.

The program can:

- Display array elements
- Calculate the sum of elements
- Find the largest element
- Find the smallest element
- Calculate the average of the elements

## 📚 Java Concepts Used

- Arrays
- Array indexing
- for loop
- Variables
- Arithmetic operators
- if-else
- Basic problem-solving and logic

## 💻 Example

For the array:

10, 20, 30, 40, 50

Example output:

Array Elements: 10 20 30 40 50
Sum: 150
Largest: 50
Smallest: 10
Average: 30.0

## ▶️ How to Run

Compile the program:

javac Main.java

Run the program:

java Main
