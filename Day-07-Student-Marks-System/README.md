# Day 07 - Student Marks System

A simple Java console-based Student Marks System created as part of my 30-Day Java Learning Journey.

## 🎯 What This Project Does

This project calculates a student's total marks, average marks, and grade using Java methods.

The program takes the student's subject marks and processes them to display the final result.

## 📚 Java Concepts Used

- Scanner
- User Input
- Methods
- Parameters
- Return values
- Variables
- Arithmetic operators
- if-else
- Basic problem-solving and logic

## 💻 Example

Student: Komal

Marks:

Java: 87  
Computer Science: 79  
Mathematics: 85

Output:

Total Marks: 251
Average Marks: 83.67
Grade: A

## ▶️ How to Run

Compile the program:

javac Main.java

Run the program:

java Main
