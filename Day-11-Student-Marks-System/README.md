# Day 11 - Student Marks System

A Java console-based Student Marks System created as part of my 30-Day Java Learning Journey.

## 🎯 What This Project Does

This project takes a student's marks, stores them using an array, and calculates the total marks, average marks, and grade.

The program uses methods to perform different calculations and conditions to determine the student's grade.

## 📚 Java Concepts Used

- Arrays
- Methods
- Parameters
- Return values
- if-else conditions
- Variables
- Arithmetic operators
- Scanner
- User input
- Basic problem-solving and logic

## 💻 Example

Student: Komal

Marks:

87  
79  
85

Output:

Total Marks: 251
Average Marks: 83.67
Grade: A

## ▶️ How to Run

Compile the program:

javac Main.java

Run the program:

java Main
