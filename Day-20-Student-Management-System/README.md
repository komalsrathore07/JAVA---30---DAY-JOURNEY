# Day 20 - Student Management System

A Java console-based Student Management System created as part of my 30-Day Java Learning Journey.

## 🎯 What This Project Does

This project manages student records using Java Collections.

The program allows the user to perform different operations on student records, such as:

- Add a student
- View all students
- Search for a student
- Update student marks
- Remove a student
- Exit the program

## 📚 Java Concepts Used

- ArrayList
- HashMap
- HashSet
- Iterator
- Classes and Objects
- Methods
- Scanner
- User Input
- Loops
- if-else conditions
- Menu-driven programming
- Collections Framework
- Basic problem-solving and logic

## 💻 Example Menu

1. Add Student
2. View All Students
3. Search Student
4. Update Marks
5. Remove Student
6. Exit

## ▶️ How to Run

Compile the program:

javac Main.java

Run the program:

java Main
