# Day 17 - Bank Account Simulator

A Java console-based Bank Account Simulator created as part of my 30-Day Java Learning Journey.

## 🎯 What This Project Does

This project simulates a basic bank account through a menu-driven console program.

The user can perform different banking operations such as:

- Check account balance
- Deposit money
- Withdraw money
- Exit the program

The program uses Object-Oriented Programming concepts to represent a bank account and manage its operations.

## 📚 Java Concepts Used

- Classes and Objects
- Methods
- Constructors
- Encapsulation
- Variables
- Scanner
- User Input
- if-else conditions
- while loop
- Menu-driven programming
- Object-Oriented Programming
- Basic problem-solving and logic

## 💻 Example Menu

1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Exit

## ▶️ How to Run

Compile the program:

javac Main.java

Run the program:

java Main
