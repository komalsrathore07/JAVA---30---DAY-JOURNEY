# Day 14 - Mini Game

A simple Java console-based Mini Game created as part of my 30-Day Java Learning Journey.

## 🎯 What This Project Does

This project is a small interactive game built using Java.

The game takes input from the user and uses conditions, loops, methods, and basic game logic to control the gameplay.

## 📚 Java Concepts Used

- Scanner
- User Input
- Methods
- Return statements
- Variables
- if-else conditions
- else-if conditions
- while loop
- Basic game logic
- Problem-solving

## 💻 Example

The player interacts with the game through the console.

The program takes the user's input, processes the choice, and displays the appropriate result.

## ▶️ How to Run

Compile the program:

javac Main.java

Run the program:

java Main
